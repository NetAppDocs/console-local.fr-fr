= Ports pour l’agent Console sur site dans le déploiement local de NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Dans le déploiement local de NetApp Console, l'agent Console utilise les ports _inbound_ lorsqu'il est installé manuellement sur un hôte Linux sur site. Consultez ces ports à des fins de planification.

Ces règles de trafic entrant s'appliquent à tous les modes de déploiement de la NetApp Console.

[cols="10,10,80"]
|===
| Protocole | Port | But 


| HTTP | 80  a| 
* Permet l'accès HTTP depuis les navigateurs Web clients à l'interface utilisateur locale
* Utilisé lors du processus de mise à niveau de Cloud Volumes ONTAP




| HTTPS | 443 | Permet un accès HTTPS depuis les navigateurs Web clients à l’interface utilisateur locale 
|===
