= Connectez votre LLM et activez l’assistant NetApp Console dans le déploiement local de NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Connectez un point de terminaison LLM pris en charge pour mettre à la disposition des utilisateurs du déploiement local de NetApp Console des instructions et des opérations de stockage en langage naturel régies.


NOTE: Cette documentation relative à la connexion d'un LLM à l'assistant Console pour activer les fonctionnalités d'IA est fournie à titre d'aperçu technologique. Dans le cadre de cette offre d'aperçu, NetApp se réserve le droit de modifier les détails, le contenu et le calendrier de cette offre avant sa disponibilité générale.

.Rôles d'accès requis
Super administrateur ou administrateur de l'organisation. link:reference-iam-predefined-roles.html["Découvrez les rôles d'accès"].

Une fois la configuration terminée, les utilisateurs ouvrent l'assistant Console depuis le tableau de bord et choisissent un mode d'accès :

* En mode *Lecture seule*, l'assistant répond aux questions et fournit des conseils sans apporter de modifications.
* En mode *Lecture/écriture*, l'assistant peut interagir avec l'infrastructure de stockage. Il affiche les détails pour vérification et confirmation avant chaque modification. Pour les opérations asynchrones, telles que la création de volume, il crée une tâche que les utilisateurs peuvent vérifier depuis l'assistant.


Pour connecter votre LLM, sélectionnez un chemin de fournisseur, saisissez les détails de l'endpoint et la clé API, puis sélectionnez un modèle dans *Administration > AI Tools*. Les actions de l’assistant restent conformes à vos politiques de stockage et à vos contrôles d’accès basés sur les rôles.



[[before-you-begin]]
== Avant de commencer

Préparez les informations d'identification du fournisseur et l'accès au point de terminaison afin que l'assistant NetApp Console puisse fonctionner dans les limites de gouvernance configurées de votre organisation.

* Votre choix de type de fournisseur : OpenAI, compatible OpenAI ou Anthropic, selon la version et le point de terminaison pris en charge.
* Une clé API valide pour le chemin du fournisseur que vous sélectionnez.
* L'URL du point de terminaison pour le chemin de votre fournisseur.
* Votre nom d'utilisateur ou votre identifiant pour le compte fournisseur LLM, le cas échéant.
* Accès réseau depuis le déploiement local de NetApp Console vers le point de terminaison sélectionné.


link:reference-llm-supported-models.html["Découvrez les fournisseurs et modèles LLM pris en charge dans le déploiement local de NetApp Console"].



[[connect-an-llm-to-netapp-console-local-deployment]]
== Connectez un LLM au déploiement local de la NetApp Console

Activez les fonctionnalités d'assistance via une configuration de fournisseur validée tout en conservant le contrôle administratif des informations d'identification des points de terminaison.

.Étapes
. Connectez-vous au déploiement local de la NetApp Console.
. Sélectionnez *Administration > Outils d'IA*.
. Sélectionnez le menu, puis sélectionnez *Modifier*.
. Dans *Type de fournisseur*, sélectionnez un type de fournisseur.
+
link:concept-llm-integration.html["Découvrez l'intégration LLM dans le déploiement local de NetApp Console"].

. Si le système vous demande un point de terminaison de fournisseur, saisissez l'URL du point de terminaison du fournisseur pour le chemin que vous avez sélectionné.
. Dans le champ *Nom d'utilisateur*, saisissez votre nom d'utilisateur ou votre identifiant SSO si le chemin de votre fournisseur l'exige.
. Dans le champ *clé API*, collez la clé API provenant du chemin de votre fournisseur sélectionné.
. Sélectionnez un modèle dans la liste.
. Vérifiez la configuration, puis sélectionnez *Enregistrer*.
+
Vérifiez le type de fournisseur, l'URL du point de terminaison, la clé API et le modèle sélectionné avant d'enregistrer la configuration.





[[verify-that-llm-integration-works]]
== Vérifiez que l'intégration LLM fonctionne

Confirmez la disponibilité de l’assistant et son comportement d’approbation afin que les utilisateurs puissent se fier à l’intégration configurée pour les opérations encadrées.

.Étapes
. Ouvrez l'assistant de console en mode lecture seule et exécutez une requête de base.
. Ouvrez l'assistant *Console assistant* en mode *Lecture/écriture* et confirmez que les actions modifiant le stockage nécessitent une confirmation de l'utilisateur avant leur exécution.
. Vérifiez que les utilisateurs qui ont besoin de flux de travail d’actions disposent des contrôles d’accès basés sur les rôles requis.


Une fois la validation terminée, les utilisateurs peuvent ouvrir l'assistant Console depuis le tableau de bord et décrire les tâches en langage clair. link:task-console-asst-use.html["Découvrez comment utiliser l’assistant NetApp Console"].



[[protect-credentials-and-monitor-llm-usage]]
== Protégez les identifiants et surveillez l'utilisation du LLM

Protégez les identifiants LLM et surveillez l'activité du fournisseur afin de réduire l'utilisation non autorisée de l'intégration et de soutenir la gouvernance organisationnelle.

* Utilisez une clé API dédiée pour l'intégration du déploiement local de Console lorsque cela est possible.
* Renouvelez les clés API conformément à la politique de votre organisation.
* Surveillez l'utilisation des API côté fournisseur et les alertes conformément aux exigences de gouvernance de votre organisation.
