La vidéo suivante présente les étapes à suivre pour s’abonner à NetApp Intelligent Services depuis AWS Marketplace :

.Abonnez-vous aux NetApp Intelligent Services depuis AWS Marketplace
video::096e1740-d115-44cf-8c27-b051011611eb[panopto]
.Étapes
. Sélectionnez *Administration > Identifiants*.
. Sélectionnez *identifiants de l'organisation*.
. Sélectionnez le menu d'actions correspondant à un ensemble d'informations d'identification associées à un agent Console, puis sélectionnez *Configurer l'abonnement*.
+
Vous devez sélectionner des identifiants associés à un agent Console. Vous ne pouvez pas associer un abonnement Marketplace à des identifiants associés à la NetApp Console.

+
image:screenshot_aws_configure_subscription.png["Capture d'écran du menu d'actions pour un ensemble d'identifiants existants."]

. Pour associer les identifiants à un abonnement existant, sélectionnez l’abonnement dans la liste déroulante et sélectionnez *Configurer*.
. Pour associer les informations d'identification à un nouvel abonnement, sélectionnez *Ajouter un abonnement > Continuer* et suivez les étapes indiquées dans AWS Marketplace :
+
.. Sélectionnez *Afficher les options d'achat*.
.. Sélectionnez *S'abonner*.
.. Sélectionnez *Configurer votre compte*.
+
Vous serez redirigé vers la NetApp Console.

.. Depuis la page *Attribution de l’abonnement* :
+
*** Sélectionnez les organisations ou les comptes Console auxquels vous souhaitez associer cet abonnement.
*** Dans le champ *Remplacer l'abonnement existant*, choisissez si vous souhaitez remplacer automatiquement l'abonnement existant d'une organisation ou d'un compte par ce nouvel abonnement.
+
La Console remplace l'abonnement existant pour toutes les informations d'identification de l'organisation ou du compte par ce nouvel abonnement. Si un ensemble d'informations d'identification n'a jamais été associé à un abonnement, alors ce nouvel abonnement ne sera pas associé à ces informations d'identification.

+
Pour toutes les autres organisations ou tous les autres comptes, vous devrez associer manuellement l'abonnement en répétant ces étapes.

*** Sélectionnez *Enregistrer*.
