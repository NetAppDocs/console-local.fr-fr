Points de terminaison contactés lors de l'installation manuelle:: Lorsque vous installez manuellement l'agent Console sur votre propre hôte Linux, le programme d'installation de l'agent Console nécessite l'accès aux URL suivantes pendant le processus d'installation :


[cols="2*"]
|===
| Points d'extrémité | But 


| \https://mysupport.netapp.com |  


| \https://signin.b2c.netapp.com | (ce point de terminaison est l’URL CNAME pour https://mysupport.netapp.com) 


| \https://cloudmanager.cloud.netapp.com/tenancy |  


| \https://stream.cloudmanager.cloud.netapp.com |  


| \https://production-artifacts.cloudmanager.cloud.netapp.com |  


 a| 
* Option 1 (recommandée) :
+
** \https://bluexpinfraprod.eastus2.data.azurecr.io
** \https://bluexpinfraprod.azurecr.io


* Option 2 :
+
** https://*.blob.core.windows.net
** \https://cloudmanagerinfraprod.azurecr.io



 a| 
Pour obtenir les images, l'installateur doit accéder à l'un de ces deux ensembles de points de terminaison. ^1^ Les points de terminaison de l'option 1 sont recommandés car ils sont plus sécurisés. Nous vous recommandons de configurer votre pare-feu pour autoriser les points de terminaison de l'option 1, tout en bloquant ceux de l'option 2. Veuillez noter les points suivants concernant ces points de terminaison :

* Les points de terminaison mentionnés dans l'option 1 sont pris en charge à partir de la version 3.9.47 de l'agent Console. Il n'y a pas de compatibilité rétroactive avec les versions précédentes de l'agent Console.
* L'agent de la Console contacte d'abord les points de terminaison listés dans l'option 2. Si ces points de terminaison ne sont pas accessibles, l'agent de la Console contacte automatiquement les points de terminaison listés dans l'option 1.
* Les points de terminaison de l'option 1 ne sont pas pris en charge si vous utilisez l'agent Console avec NetApp Backup and Recovery ou NetApp Ransomware Resilience. Dans ce cas, vous pouvez interdire les points de terminaison listés dans l'option 1, tout en autorisant ceux listés dans l'option 2.
