Connectez-vous à la Console et associez l'agent de la Console à votre organisation. La façon dont vous vous connectez dépend du mode dans lequel vous utilisez la Console. Si vous utilisez la Console en mode standard, vous vous connectez via le site web SaaS. Si vous utilisez la Console en mode restreint ou privé, vous vous connectez localement depuis l'hôte de l'agent de la Console.

.Étapes
. Ouvrez un navigateur Web et saisissez l'URL de l'hôte de l'agent de la Console :
+
L'URL de l'hôte de la Console peut être un localhost, une adresse IP privée ou une adresse IP publique, selon la configuration de l'hôte. Par exemple, si l'agent de la Console se trouve dans le cloud public sans adresse IP publique, vous devez saisir une adresse IP privée d'un hôte ayant une connexion à l'hôte de l'agent de la Console.

. Inscrivez-vous ou connectez-vous.
. Après vous être connecté, configurez la Console :
+
.. Spécifiez l'organisation Console à associer à l'agent Console.
.. Saisissez un nom pour le système.
.. Sous *Exécutez-vous dans un environnement sécurisé ?*, laissez le mode restreint désactivé.
+
Le mode restreint n'est pas pris en charge lorsque l'agent Console est installé sur site.

.. Sélectionnez *Let's start*.
